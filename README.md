# Harapanku Semua — Rumah Sakit

Website landing page untuk **Rumah Sakit Harapanku Semua**, rumah sakit fiktif yang mengedepankan pelayanan kesehatan dengan kasih dan sepenuh hati.

## Teknologi

- **HTML5** — struktur halaman
- **CSS3** — styling (custom, tanpa framework)
- **JavaScript (Vanilla)** — interaksi & animasi
- **Font Awesome** — ikon
- **Google Fonts** — Plus Jakarta Sans, Inter, Manrope

Tanpa framework, tanpa build tool. Buka langsung di browser.

## Struktur Folder

```
kesehatan/
├── index.html          # Halaman utama
├── js/
│   └── main.js         # Logika interaksi (scroll, counter, search)
├── style/
│   └── style.css       # Semua styling
├── img/                # Aset gambar
└── README.md
```

## Fitur

- **Hero section** dengan pencarian lokasi
- **Statistik animasi** — angka pasien, tingkat keberhasilan, dokter ahli (count-up saat scroll)
- **Spesialisasi** — 8 layanan medis (Kardiologi, Neurologi, Ortopedi, dll.)
- **Fasilitas** — bento grid gallery
- **Banner CTA** — call-to-action
- **Footer** — kontak & navigasi
- **Scroll progress bar** di navbar
- **Responsive** — mobile-friendly

## Cara Menjalankan

Karena ini static site, tidak perlu install apapun:

```bash
# Opsi 1: langsung buka file
open index.html

# Opsi 2: pakai live server (opsional)
npx live-server .
```

Atau cukup buka `index.html` di browser.
